# Auth-Duality Yin-Yang Auth-Duality

This folder contains only the selected auth-duality button variant and the reusable
animation primitives used by Storybook demos.

## Files

- `ZenDualityButton.tsx` - selected dual-option animated button
- `LoginButton.tsx` - wrapper that uses `ZenDualityButton` with mock modal flow
- `TextToIcon.tsx` - isolated text/icon animation component
- `useAuthToggleSideTransitions.ts` - side transition policy hook
- `useZenDualitySeamAnimation.ts` - seam/ying path animation hook
- `authToggleMotion.ts` - shared motion constants and delay utility
- `auth-duality-liquid-yinyang-auth-toggle-anime.css` - styles for the auth-duality UI
- `wash-in-sea/WashInSea.tsx` - reusable "wash away" text animation
- `wash-in-sea/BlackHoleWhirlpool.tsx` - reusable black-hole text animation
- `wash-in-sea/prepareCharacterItems.ts` and `wash-in-sea/blackHoleConstants.ts` - black-hole helper utilities
- `wash-in-sea/wash-in-sea.css` and `wash-in-sea/black-hole-whirlpool.css` - animation styles
